## What is NOMAN?

**NOMAN** is a distributed IoT-based mine monitoring system designed to
continuously observe ground movement and structural instability in mining
environments.

A network of ESP32-based sensor nodes collects acceleration data using
ADXL345 accelerometers and transmits it to a centralized FastAPI backend.

The system provides:

- 📡 **Distributed wireless sensing**
- 📊 **Real-time acceleration monitoring**
- 🟢 **Live node health & connectivity**
- 📈 **Historical sensor visualization**
- ⚠️ **Foundation for anomaly detection & early warnings**
- 🌐 **Centralized web-based monitoring dashboard**
